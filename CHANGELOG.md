# Changelog

## 0.2.0 - 2026-08-03

- Replace notebook-derived flat modules with an installable `sgdlm` package.
- Add general exogenous regressors and arbitrary contemporaneous parent masks.
- Add reproducible posterior forecasting, terminal IRFs, and evolving time-varying IRFs.
- Add model artifacts, CLI commands, FastAPI endpoints, Docker, tests, linting, and CI.
- Organize executable workflows under `scripts/` and YAML configurations under `config/`.
- Add a persisted, resource-oriented FastAPI model API and a Streamlit analysis workbench.
